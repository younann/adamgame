# Audio credits — all CC0 (public domain)

Every shipped sound and music file under `public/audio/sfx`, `public/audio/music` and
`public/audio/amb` comes from a source whose page states **CC0 1.0 (Creative Commons Zero)**,
or was generated in-house. No attribution is legally required; we credit authors anyway.
Licenses were checked on each source page on 2026-10-03. Where an OpenGameArt entry offered
several licenses (e.g. CC0 + OGA-BY), we use it under **CC0**. Anything CC-BY-only,
NC, SA or ambiguous was rejected (e.g. "Well Done", whose filename says CCBY3).

Rebuild: `scripts/audio/fetch-sources.sh <dir> && python3 scripts/audio/build-audio.py <dir>`.
