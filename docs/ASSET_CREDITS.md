Location in the project: `public/game/models/characters/` (+ `Textures/colormap.png`).

Everything else in the 3D stadium (pitch, stands, crowd, goal + net, floodlights, LED boards,
flags, football, number boards, Sparky 3D, trophy, particles) is generated procedurally in
code (`src/game/scenes/Football3D/`).

The 3D world map (`src/game/scenes/World3D/`: sky, sea, island, trees, landmarks, portals, gift
box) is also fully procedural — no external art.
Turbo Racing 3D (`src/game/scenes/Racing3D/`) and Hero City 3D (`src/game/scenes/HeroCity3D/`) are
likewise fully procedural.
